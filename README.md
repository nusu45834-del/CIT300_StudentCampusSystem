# CIT300 - Data Structures and Algorithms

## Graded Practical Assignment 1

### University Student Record and Campus Route Management System

---

## Project Description

This project is a Java console-based application developed
to manage university student records and campus routes.

The system demonstrates the following data structures:

- Linked List
- Stack
- Queue
- Binary Search Tree
- Hash Table
- Graph
- Breadth First Search

---

## Main Features

### Student Management

- Add student
- Update student
- Delete student
- Search student
- Display students

### Data Structures

- Linked List for student records
- Stack for recent actions
- Queue for service requests
- BST for organizing students
- Hash Table for student ID searching
- Graph for campus locations
- BFS for campus traversal
